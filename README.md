# NEON DRIFT // LAST LIGHT

A polished neon arcade survival game written entirely in Python with Pygame.

## Repository name

`neon-drift-last-light`

## Features

- Fast twin-stick-style arcade combat
- WASD movement + mouse aiming/shooting
- Energy-powered weapons
- Dash with invulnerability
- Shield, energy and overdrive pickups
- Dynamic waves that get harder over time
- Combo multiplier and score chasing
- Three enemy types
- A boss fight: **THE WARDEN**
- Particles, glow effects, screen shake, neon grid and animated UI
- No external art, audio or font files required

## Run

```bash
pip install pygame
python main.py
```

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Aim |
| Left Mouse | Fire |
| Space | Dash |
| ESC | Pause / return |
| Enter | Start / restart |

## Goal

Survive the waves, build your combo, collect power-ups and destroy **THE WARDEN** when the boss arrives.

Have fun — and chase a ridiculous high score.
